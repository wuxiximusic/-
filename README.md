# Cyber Piano 88 Visualizer

Cyber Piano 88 Visualizer is an interactive web-based music visualization project that transforms piano music into a futuristic field of cyber light pillars. The system is inspired by the structure of the 88-key piano keyboard. Each virtual pillar represents one piano key, from the lowest register to the highest register.

When music is played or an MP3 file is uploaded, the website analyzes the sound in real time. The visual pillars respond to the changing frequency and volume of the music. Lower sounds activate lower-register pillars, while higher sounds activate higher-register pillars. Louder sounds make the corresponding pillars rise higher and glow more brightly, creating a dynamic visual connection between pitch, intensity, and space.

The visual design uses a cyber-style aesthetic: glowing columns, neon colors, a dark digital stage, and flowing light effects. The goal of this project is to explore the relationship between music and visual art, especially how piano sound can be translated into spatial, colorful, and animated forms.

This project can be used as a creative music visualization tool, a digital piano teaching aid, or an experimental platform for studying audiovisual interaction. It is especially useful for demonstrating musical elements such as pitch range, dynamics, register contrast, chord density, and the movement of musical energy.

Main features:

* 88-key piano-inspired visual structure
* MP3 music upload and real-time audio analysis
* Cyber-style 3D light pillar visualization
* Pitch-region response based on audio frequency
* Volume-based height and brightness changes
* Built-in demo music for quick testing
* Browser-based operation without additional software installation

This is an early prototype. Future versions may include more accurate pitch recognition, MIDI input, real-time piano keyboard connection, customizable visual styles, recording/export functions, and improved performance for large-screen projection or live performance use.
